# Atividade-Avaliativa-2---Do-Problema-ao-Sistema-Orientado-a-Objetos
Avaliação de Programação Orientada a Objetos em dupla.
O programa foi criado na linguagem Python utilizando a versão Python 3.13.2. As bibliotecas aplicadas foram “abc” e “datetime”, como no Python não é necessário a separação de arquivos, o código inteiro foi colocado em um único arquivo com o nome emprestimo.py.
No plano inicial, realizado em aula no dia 16/10, está escrito nossas intenções para o sistema, que contempla o campo de cadastro dos usuários, os equipamentos disponíveis, opções de empréstimo e devolução, o prazo de validade do empréstimo, além de registrar de forma eficiente o histórico e a atualização dos utensílios emprestados. Felizmente, todas essas metas foram alcançadas e implementadas no código.
A divisão de tarefas foi seguida como no planejamento, com exceção da classe “Equipamentos” que teve também a ajuda da Luiza. 
A única mudança nas datas do plano de ação foi a pesquisa antes do início da criação do código que também foi feita em 19/10.
